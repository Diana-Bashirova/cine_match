#  CineMatch - Совместный подбор фильмов

Веб-приложение для совместного выбора фильмов с друзьями на основе предпочтений всех участников.

##  Быстрый запуск

### Требования
- Docker Desktop
- Git

### Установка

  Bash
# 1. Клонируйте репозиторий
git clone https://github.com/Diana-Bashirova/cine_match.git
cd cine_match

# 2. Запустите приложение
docker-compose up --build
  

### Доступные адреса
- **Фронтенд**: http://localhost:3000
- **Backend API**: http://localhost:8000
- **Swagger документация**: http://localhost:8000/api/schema/swagger-ui/
- **Django Admin**: http://localhost:8000/admin/

###  Тестовые аккаунты

**Администратор:**
- Логин: Admin
- Пароль: Admin123

**Обычные пользователи:**
- Логин: user1 / Пароль: qwerty123

##  База данных

Репозиторий содержит предзаполненную базу данных db_copy.sqlite3 (42 MB) с:
- 1000+ фильмов из IMDb
- Тестовыми пользователями
- Примерами комнат и голосований
- Историей просмотров и оценок

### Просмотр в DBeaver
1. Откройте DBeaver
2. Database → New Database Connection → SQLite
3. Укажите путь: db_copy.sqlite3
4. Просматривайте таблицы: фильмы, пользователи, голоса, история

##  CI/CD Pipeline

Проект настроен с автоматическим пайплайном:
1. **Lint** - проверка стиля кода (flake8, black, isort)
2. **Test** - запуск unit-тестов с покрытием
3. **Build** - сборка Docker образа
4. **Deploy** - автоматический деплой (опционально)

##  Решение проблем

### Приложение не запускается
  Bash
docker-compose down
docker-compose up --build
  

### База данных не загружается
  Bash
docker volume rm cine_match_sqlite_db
docker-compose up --build
